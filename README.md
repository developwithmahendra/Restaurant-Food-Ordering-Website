# Saffron & Salt – Restaurant & Food Ordering Website
Plain HTML, CSS and JavaScript. No build step.

- Open `index.html` in a browser (pages: `index.html`, `menu.html`, `contact.html`).
- `css/style.css` – theme, layout, animations, responsive rules
- `js/main.js` – slider, menu, order drawer, forms
- `screenshots/` – desktop, tablet, mobile and dark-mode captures

## Deploy
GitHub Pages: upload these files to a repository, then Settings → Pages → main branch, root folder.
Netlify: drag this folder onto app.netlify.com → Add new site → Deploy manually.

Replace the placeholder address and phone number in `contact.html`.
